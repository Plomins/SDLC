## Описание проекта

**Калькулятор Жизни** — десктопное приложение на Java, которое по введённой
дате рождения рассчитывает статистические показатели жизни человека,
основанные на среднестатистических данных из открытых источников.

Программа показывает:

- Сколько часов и суток человек проспал;
- Сколько раз моргнул;
- Сколько ударов сделало сердце;
- Сколько литров воды выпил человек;
- Сколько раз смеялся.

---

## Функциональные возможности

- Ввод даты рождения через отдельное диалоговое окно (без использования
  стандартного `JDatePicker` — только три текстовых поля: день, месяц, год).
- Валидация ввода:
  - день, месяц, год — только числа;
  - день ≤ 31, месяц ≤ 12, год ≥ 1900 и не в будущем;
  - дата должна существовать (например, 31 февраля отклоняется).
- Автоматический пересчёт всех показателей после ввода.
- Сохранение последней введённой даты в файл между запусками приложения.
- Восстановление последней даты в диалоге ввода при повторном открытии.
- Отображение сообщений об ошибках при некорректном вводе.

## Архитектура

Проект построен по паттерну **MVC (Model-View-Controller)** с **активной моделью**:

- **Model** (`LifeCalculatorModel`) — хранит дату рождения, вычисляет статистику,
  реализует интерфейс `IObservable` и уведомляет наблюдателей при изменении.
- **View** (`MainView`, `InputView`) — отображает результаты и форму ввода.
  `MainView` реализует интерфейс `IObserver` и обновляется автоматически.
- **Controller** (`Controller`) — обрабатывает нажатия кнопок, открывает диалог,
  валидирует данные и передаёт их в модель.

Сохраняется вся история изменений даты — последнее значение пишется в файл
`~/.life_calculator.properties`.
